# lxsession Spec

`lxsession` is not implemented yet.

The idea has been folded into the global roadmap so future planning stays in
one place. See the [`lxsession` roadmap entry](../ROADMAP.md#lxsession) for the
current shape.

Short version: the main hook is restoring/switching named desktop profiles by
moving existing windows, spawning missing ones, and handling unrelated windows
by policy. It is not meant to restore full application state.
