# lxrunner Remaining Work

`lxrunner` already exists and is no longer just a proposal.

This file only tracks what is still wanted for the module.

## Still Wanted

- keep polishing alias/result presentation
  Why: aliases now support glyphs and image icons, but the result list can
  still become easier to scan

- consider later result-row metadata such as a small source indicator or
  description when it clearly improves usability
  Why: useful, but lower priority than finishing broader repo work

## Explicit Non-Goals For Now

- no plugin system
  Why: far beyond the intended scope

- no window switcher mode
  Why: that is a different tool/problem space

- no attempt at full Rofi feature parity
  Why: `lxrunner` is meant to stay narrow and Awesome-native
